# 05 Local evidence vault

Serves: G-3, G-5.

Ingest CSV and PDF statements (including password-protected PDFs), ePRC and S-PRC certificates, FBR returns, invoices and contracts on the applicant's machine. Deterministic parsers, rule classifier, redacted model fallback for ambiguous rows, review of uncertain rows, deduplication (ADR-0028). Evaluation on seeded synthetic evidence (ADR-0021).
