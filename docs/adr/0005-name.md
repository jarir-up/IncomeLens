# ADR-0005: Name: PakkiFile

- Status: Approved
- Approved by: Muhammad Jariruddin, 2026-10-30

## Context
The name should be local, grounded and honest about the job.

## Decision
Product name PakkiFile (from "file pakki hai"). GitHub description: "Open-source, local-first evidence compiler for freelancers' visa, loan and rental files." Motto "Lint your file before they do" is provisional and is not used anywhere until launch.

## Consequences
No domain in v0; the checklist lives at the free GitHub Pages address. Before launch the owner searches the IPO Pakistan register (classes 9 and 42); if clear, register pakkifile.com at launch. On 2026-10-30 the .com, .org, .dev, .app and .pk domains had no DNS records and no product used the name.
