# ADR-0003: Registry built from real public official documents

- Status: Approved
- Approved by: Muhammad Jariruddin, 2026-10-29

## Context
Fictional insurers and institutions made evaluation easy but the product useless.

## Decision
The registry is built from real, public, official documents: embassy and visa-centre checklists, SBP circulars, FBR guidance. Synthetic data is used only for applicant evidence in evaluation, where hidden ground truth is needed.

## Consequences
Real-world documents from day one. Source changes must be tracked (ADR-0007). Copyrighted text is cited and summarised, not republished wholesale.
