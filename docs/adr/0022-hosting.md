# ADR-0022: Free-tier hosting, chosen at deploy time

- Status: Superseded by ADR-0030
- Approved by: Muhammad Jariruddin, 2026-10-07 (IncomeLens ADR-013, carried forward)

## Context
No budget for paid infrastructure.

## Decision
Free-tier options only (for example Railway, Render, or self-hosted with tunnelling). Choose when the hosted checklist first deploys.

## Consequences
Keep deploy config minimal and portable.
