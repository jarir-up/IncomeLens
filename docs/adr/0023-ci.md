# ADR-0023: GitHub Actions CI

- Status: Approved
- Approved by: Muhammad Jariruddin, 2026-10-07 (IncomeLens ADR-014, carried forward)

## Context
One pipeline for checks, the rules gate and the evaluation gate.

## Decision
GitHub Actions runs `scripts/check.sh`, the rules gate, and the evaluation gate on frozen sets.

## Consequences
Fails on regression beyond tolerance. The rules gate is disabled from 2026-10-30 while the project runs on zero spend; see `docs/PROGRESS.md`.
