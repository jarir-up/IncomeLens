# ADR-0010: No monetisation in v0

- Status: Approved
- Approved by: Muhammad Jariruddin, 2026-10-30

## Context
Earning is not the goal now; a pitch line would be invented rather than discovered.

## Decision
No pricing, paid tier or value-proposition line in v0. Revisit only if a need appears after launch.

## Consequences
Free hosting only (ADR-0030).
