# ADR-0002: Open source and local-first; hosted surfaces hold no personal data

- Status: Approved
- Approved by: Muhammad Jariruddin, 2026-10-29

## Context
Freelancers will not upload bank statements to an unknown startup. The first users are developers who can run software locally and read its code.

## Decision
The code is open source. Anything that touches an applicant's documents runs on the applicant's machine. The hosted surface serves the registry only and never receives personal data.

## Consequences
Trust comes from inspectable code, not promises. Hosting is cheap and low-risk. Usage can only be measured through opt-in pings. Licence pending (Q-2).
