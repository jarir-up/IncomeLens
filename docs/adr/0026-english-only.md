# ADR-0026: English only in v1

- Status: Superseded by ADR-0033
- Approved by: Muhammad Jariruddin, 2026-10-07 (IncomeLens ADR-017, carried forward)

## Context
Keep v1 simple.

## Decision
English for synthetic data, queries, UI and docs. No Roman Urdu in v1.

## Consequences
Real memos contain Roman Urdu now that real users run the app (Q-4).
