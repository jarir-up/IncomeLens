# PakkiFile

**Lint your file before they do.**

Open-source, local-first evidence compiler for freelancers' visa, loan and rental files.

Freelancers with real, steady foreign income get refused or delayed because their papers don't tell one consistent story in the form the reviewing authority expects. PakkiFile tells you what an authority actually requires, checks your documents against it and against each other, and assembles a file where every figure traces back to a source page.

- Your documents stay on your machine.
- Requirements come from official, public sources, each with a citation and a confidence level.
- It never predicts approval and never helps hide anything.

**Status:** design locked, build starting. First authority: Schengen (Germany, Italy, France).
